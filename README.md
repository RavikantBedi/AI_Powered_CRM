# AI Personal CRM

An AI-powered personal CRM system for managing relationships, contacts, and interactions with intelligent insights.

## Features

- **Contact Management**: Organize and manage all your personal and professional contacts
- **Timeline Tracking**: Keep track of all interactions with each contact
- **AI-Powered Insights**: Get intelligent relationship recommendations and follow-up suggestions
- **Task Management**: Create and track follow-up tasks and reminders
- **Dashboard Analytics**: View relationship insights and activity heatmaps
- **Email Integration**: Sync emails and extract insights from communications
- **RAG-Based Search**: Search through contact history with AI-powered semantic understanding

## Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: PostgreSQL with Prisma ORM
- **Cache**: Redis
- **AI**: OpenAI API for embeddings and analysis
- **Authentication**: NextAuth.js
- **Payments**: Stripe

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see `.env.example`)
4. Run the development server: `npm run dev`
5. Open http://localhost:3000
